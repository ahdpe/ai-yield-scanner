# 🚀 AI Yield & Inefficiency Scanner ($5,000 USDC)

Алгоритмическая система выявления неэффективностей на рынках предсказаний (**Polymarket**) и некастодиальных деривативах (**Hyperliquid L1**) с семантическим контролем рисков через **Venice AI (`gemini-4-argon`)** и интерактивным Telegram-ботом.

---

## 🎯 Архитектура стратегий

1. **Polymarket Liquidity Rewards (`poly_mm`):**
   * Размещение двусторонних лимитных ордеров в коридоре спреда для сбора ежедневных выплат в чистом USDC.
   * Фильтрация волатильных лайв-матчей (спорт/киберспорт).
   * **ИИ Kill-Switch:** автоматическая отмена и безопасная перестановка лимиток при резком сдвиге рыночной цены (>1.0¢/час) до пробоя коридора.

2. **Polymarket Smart Bonding (`poly_bond`):**
   * Выкуп исходов с вероятностью 97.0¢–99.4¢ перед финальной резолюцией оракулом UMA.
   * Глубокий юридический аудит текста правил (`description`) через флагманский ИИ для исключения задержек сертификации и ловушек.

3. **Hyperliquid Funding Persistence (`hl_funding`):**
   * Поиск крупных рынков (Open Interest > $15M) с аномальной ставкой финансирования (>20% APR).
   * Проверка устойчивости за последние 72 часа (отсечение кратковременных 1-часовых ложных всплесков).

---

## 📁 Структура проекта

* `ai_analyzer.py` — модуль семантического риск-аудита рынков через Venice AI (`http://127.0.0.1:8787/api/v1` или `api.venice.ai`).
* `polymarket_scanner.py` — сканер активных рынков Polymarket Gamma API.
* `hyperliquid_scanner.py` — сканер ставок финансирования и стаканов Hyperliquid L1.
* `paper_trader.py` — непрерывный демон честной симуляции портфеля $5,000 USDC.
* `telegram_bot.py` — интерактивный Telegram-бот для управления, просмотра портфеля и логов.
* `telegram_notifier.py` — модуль push-уведомлений в реальном времени.
* `run_scanner.py` — CLI-скрипт сканирования для разовых срезов рынка.

---

## ⚙️ Установка и запуск

```bash
# Разовый анализ рынка на депозит $1,000 или $5,000:
python3 run_scanner.py --deposit 5000

# Запуск демона симуляции:
python3 paper_trader.py --deposit 5000 --interval 900

# Просмотр текущего статуса:
python3 paper_trader.py --status
```
